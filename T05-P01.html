1. What is sequence?

Sequence is the order in which instructions are carried out. In a sequence, instructions are performed one after another, from the first statement to the next, until the sequence is complete.

A simple program often follows this pattern:

Receive the required input.

Process the data.

Display the result.

The order matters. If a program tries to calculate a total before receiving the values it needs, the result may be incorrect or the program may not work as intended.

2. A simple sequence

Problem: Input two numbers, calculate their sum and display the answer.

DECLARE FirstNumber : INTEGER
DECLARE SecondNumber : INTEGER
DECLARE Total : INTEGER

INPUT FirstNumber
INPUT SecondNumber
Total ← FirstNumber + SecondNumber
OUTPUT Total

The statements are carried out in this order:

There is no decision or loop in this example. Each statement is performed once, in order.

3. Assignment

An assignment statement stores a value in a variable. In Cambridge-style pseudocode, the assignment operator is the left arrow: ←.
<identifier> ← <value>

The identifier on the left must be a variable. The value on the right may be a literal value, another variable or an expression that produces a value of a compatible data type.

Examples:

Score ← 75
Name ← "Amina"
Total ← Price * Quantity
Counter ← Counter + 1

The expression on the right is evaluated first. The resulting value is then stored in the variable on the left.

4. Updating a variable

An assignment can use the current value of a variable to calculate its new value.

Counter ← 4
Counter ← Counter + 1

The first statement stores 4 in Counter. The second statement adds 1 to the current value and stores the result back in Counter. The final value is 5.

This does not mean that the equals sign in mathematics has changed. The assignment arrow means 'calculate the right-hand side and store the result in the variable on the left'.

5. Follow the order of assignment

Consider the following statements:

A ← 6
B ← 3
A ← A + B
B ← A - B

Trace the values after each statement.

The final values are A = 9 and B = 6. Each statement uses the values available at the time it is executed.

6. Sequence with input, calculation and output

Problem: A shop program receives the price of one item and the number purchased. It calculates and displays the total cost.

DECLARE Price : REAL
DECLARE Quantity : INTEGER
DECLARE TotalCost : REAL

INPUT Price
INPUT Quantity
TotalCost ← Price * Quantity
OUTPUT "Total cost: ", TotalCost

The sequence is important: the program receives Price and Quantity before using them in the calculation.

7. Assignment in Python 3

Python uses the equals sign (=) for assignment. Cambridge pseudocode uses ←. Do not confuse the two notations.
count = 10
count = count + 1
print(count)

The output is 11. Python evaluates the expression on the right and assigns the result to the variable on the left.

8. Common mistakes

9. Quick check

1. What does sequence mean?

Answer: Instructions are carried out one after another in their written order.

2. Which symbol is used for assignment in Cambridge pseudocode?

Answer: ←.

3. What does Total ← A + B do?

Answer: Adds A and B and stores the result in Total.

4. If Count is 7, what is the value after Count ← Count + 2?

Answer: 9.

5. In an assignment statement, which side contains the variable receiving the value?

Answer: The left-hand side.

6. What symbol does Python use for assignment?

Answer: =.

A statement may depend on values created by earlier statements. If statements are in the wrong order, a value may be used before it is available and the result may be incorrect.

Remember these key points

Sequence means executing instructions in their written order.

A sequence can contain input, assignment, calculations and output.

Cambridge pseudocode uses ← as the assignment operator.

The right-hand expression is evaluated before its result is stored on the left.

A variable can be updated using its current value.

Python uses = for assignment; Cambridge pseudocode uses ←.
