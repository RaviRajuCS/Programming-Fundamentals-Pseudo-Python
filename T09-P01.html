1. What is a two-dimensional array?

A two-dimensional (2D) array stores elements in a table-like structure made up of rows and columns. Each element is identified by two indexes: one for its row and one for its column.

For example, a teacher could store marks for 3 students across 4 tests in a 2D array. Each row represents a student, and each column represents a test.

In this example, Marks[2,3] refers to the value in row 2, column 3: 69.

2. Declaring a two-dimensional array

A Cambridge pseudocode 2D array declaration specifies the lower and upper bounds for both dimensions, followed by the data type.

DECLARE <identifier> : ARRAY[<row lower>:<row upper>, <column lower>:<column upper>] OF <data type>

Example: store marks for 3 students and 4 tests, using indexes that start at 1.

DECLARE Marks : ARRAY[1:3, 1:4] OF INTEGER

This declaration creates 3 × 4 = 12 integer elements. The first index identifies the row; the second index identifies the column.

3. Accessing and updating an element

Use the array name followed by two index values inside square brackets. Separate the indexes with a comma.

Marks[2,3] ← 69

This assigns 69 to the element in row 2, column 3. To output that element:

OUTPUT Marks[2,3]

The two index values must be within the declared bounds. For Marks[1:3, 1:4], valid row indexes are 1 to 3 and valid column indexes are 1 to 4.

4. Nested iteration

To visit every element in a 2D array, use one loop inside another. This is called nested iteration. The outer loop can control the row, while the inner loop controls the column.

Worked example: input a value into every element of the Marks array.

FOR Row ← 1 TO 3\n  FOR Column ← 1 TO 4\n    INPUT Marks[Row, Column]\n  NEXT Column\nNEXT Row

For each row, the inner loop visits all four columns. When the inner loop finishes, the outer loop moves to the next row.

5. Output every element

The same nested loop structure can be used to output every element.

FOR Row ← 1 TO 3\n  FOR Column ← 1 TO 4\n    OUTPUT Marks[Row, Column]\n  NEXT Column\nNEXT Row

The elements are visited row by row: all columns in row 1, then all columns in row 2, and finally all columns in row 3.

6. Processing values in a 2D array

Nested loops can also process the data. This example calculates the total of all 12 marks.

Total ← 0\nFOR Row ← 1 TO 3\n  FOR Column ← 1 TO 4\n    Total ← Total + Marks[Row, Column]\n  NEXT Column\nNEXT Row\nOUTPUT Total

Total is set to zero before the loops. Each element is added once. The inner loop completes all columns before the outer loop moves to the next row.

7. Python 3 comparison

Python commonly represents a 2D collection using a list of lists. Python indexes start at 0, unlike the 1-based indexes used in the Cambridge example above.

marks = [\n [65, 72, 80, 74],\n [81, 77, 69, 90],\n [55, 68, 73, 70]\n]

Access row 2, column 3 in Python using marks[1][2], because both indexes start at 0.

print(marks[1][2]) # displays 69\nmarks[1][2] = 75 # updates that element

Nested loops can visit every element:

for row in range(3):\n for column in range(4):\n print(marks[row][column])

Remember: Cambridge pseudocode writes two indexes together, for example Marks[2,3]. Python list-of-lists uses two pairs of brackets, for example marks[1][2].

8. Common mistakes

Reversing the row and column indexes.

Using only one index when accessing a 2D array element.

Using an index outside the declared bounds.

Forgetting that the inner loop must finish before the outer loop moves to the next row.

Using the wrong loop limits and missing a row or column.

Confusing Cambridge 2D array syntax, Marks[Row, Column], with Python list-of-lists syntax, marks[row][column].

Key points to remember

A 2D array stores data in rows and columns.

Each element is accessed using two indexes: row first, then column.

A Cambridge declaration specifies the bounds of both dimensions.

Nested iteration is used to visit all elements in a 2D array.

Python lists of lists use zero-based indexing and two bracket pairs.

Check row and column limits carefully to avoid accessing an invalid index.
