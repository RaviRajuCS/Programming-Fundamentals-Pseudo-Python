1. Variables

A variable is a named memory location used to store a value while a program is running. The value stored in a variable can change as the program executes.

Example: a program stores a learner's test mark in a variable called Mark.

DECLARE Mark : INTEGER
Mark ← 85
Mark ← 92

After the first assignment, Mark contains 85. After the second assignment, its value is 92. The new value replaces the previous value.

2. Constants

A constant is a named value that does not change while the program runs. Constants are useful when a value is fixed and used in several places.

CONSTANT PassMark ← 50

The program can use PassMark whenever it needs to compare a score with the pass mark. In Cambridge pseudocode, a constant declaration uses a literal value; do not use a variable, another constant or an expression as the declared value.

3. Identifiers and naming

An identifier is the name given to a program element such as a variable or constant. A good identifier makes the purpose of the stored value clear.

Use meaningful names and follow the naming rules of the language being used. Avoid names that are difficult to understand, such as x1 or a2, unless they are appropriate for a short mathematical expression.

For Cambridge IGCSE pseudocode, identifiers use Pascal case: they begin with a capital letter and contain only letters and digits. Do not use underscores or other special characters. Identifiers are treated as case-insensitive, so Count and COUNT must not be used as different identifiers.

In Cambridge-style pseudocode, identifiers are written as names in declarations and statements. In Python, identifiers are case-sensitive: score and Score are different names.

4. Data types

A data type describes the kind of value a variable can store. Choosing a suitable data type helps a program store and process information correctly.

Use INTEGER for a count or a whole-number mark. Use REAL when a calculation may produce a fractional value. Use CHAR for one character, STRING for text, and BOOLEAN for a condition that is either true or false.

5. Choosing a suitable data type

A common mistake is choosing a numeric type for data that is made of digits but is not used in calculations. For example, a telephone number or learner ID may be better stored as a STRING if leading zeros or non-numeric symbols must be preserved.

6. Declaring variables in Cambridge-style pseudocode

A variable declaration identifies the variable and states its data type. The following examples use Cambridge-style pseudocode.

DECLARE Age : INTEGER
DECLARE Average : REAL
DECLARE Initial : CHAR
DECLARE LearnerName : STRING
DECLARE HasPassed : BOOLEAN

The declaration tells the reader what kind of value each variable is intended to hold.

7. Assigning values

Assignment stores a value or the result of an expression in a variable. Cambridge-style pseudocode uses the assignment arrow ←.
DECLARE Score : INTEGER
Score ← 78
Score ← Score + 5

The final value of Score is 83. The expression on the right is evaluated first, and the result is stored in the variable on the left.

Python uses the equals sign (=) for assignment. This is not the same symbol as the Cambridge pseudocode assignment arrow.

score = 78
score = score + 5
print(score)

8. Constants in pseudocode and Python

A constant is declared using CONSTANT, followed by its identifier, the assignment arrow and a literal value. Cambridge-style pseudocode uses the form shown below.

CONSTANT MaximumAttempts ← 3

Python does not have a special keyword that makes a variable truly constant. By convention, programmers use uppercase names to indicate that a value should not be changed.

MAXIMUM_ATTEMPTS = 3

The uppercase name is a convention; Python itself does not prevent the program from assigning a new value to it.

9. Type awareness in Python

Python determines the type of a value at runtime. The built-in type() function can be used to inspect a value's type.

age = 16
average = 82.5
initial = 'R'
name = "Amina"
has_passed = True

print(type(age))
print(type(average))
print(type(initial))
print(type(name))
print(type(has_passed))

In Python, a single character is represented using the str type; Python does not have a separate built-in CHAR type. Boolean values are written True and False, with initial capital letters.

10. Quick check

1. What is a variable?

Answer: A named memory location whose stored value can change.

2. What is a constant?

Answer: A named value intended to remain fixed during program execution.

3. Which data type is suitable for the number of students?

Answer: INTEGER.

4. Which data type is suitable for a student's full name?

Answer: STRING.

5. Which data type stores TRUE or FALSE?

Answer: BOOLEAN.

6. What is the final value after Score ← 12 followed by Score ← Score + 3?

Answer: 15.

7. Does Python have a separate built-in CHAR type?

Answer: No. A single character is stored as a one-character string.

Remember these key points

A variable stores a value that can change.

A constant stores a value intended to remain fixed.

An identifier is the name of a variable or constant.

INTEGER stores whole numbers; REAL stores numbers that may have fractional parts.

CHAR stores one character; STRING stores text; BOOLEAN stores TRUE or FALSE.

Cambridge-style pseudocode uses DECLARE and ← for declaration and assignment.

Python uses = for assignment and does not have a separate CHAR type.
