1. Why use procedures and functions?

A procedure or function is a named section of code that performs a particular task. It can be used whenever that task is needed. This avoids repeating the same instructions and helps make a program easier to read, test and maintain.

A procedure performs a task. It does not return a value as its result.

A function performs a task and returns one value to the place where it was called.

Cambridge pseudocode procedures and functions are defined at the start of the code, before the main program statements that use them.

2. Defining and calling a procedure without parameters

A procedure without parameters does not receive data from the calling code.

Cambridge pseudocode definition:

PROCEDURE DisplayWelcome\n  OUTPUT "Welcome to the program"\nENDPROCEDURE

Calling the procedure:

CALL DisplayWelcome

CALL transfers control to the procedure. When the procedure reaches ENDPROCEDURE, execution continues after the CALL statement.

3. Procedures with parameters

A parameter is a variable listed in the procedure definition. It receives a value when the procedure is called. The value supplied in the call is called an argument.

Cambridge pseudocode definition:

PROCEDURE DisplayName(Name : STRING)\n  OUTPUT "Hello ", Name\nENDPROCEDURE

Calling the procedure with an argument:

CALL DisplayName("Amina")

The argument "Amina" is passed to the parameter Name. The procedure displays Hello Amina.

A procedure can have more than one parameter. Cambridge syllabus guidance allows procedures and functions to have up to three parameters.

PROCEDURE DisplayTotal(Item1 : INTEGER, Item2 : INTEGER)\n  OUTPUT Item1 + Item2\nENDPROCEDURE\n\nCALL DisplayTotal(12, 8)

The two arguments are matched to the parameters in the same order: Item1 receives 12 and Item2 receives 8.

4. Defining and calling a function

A function is similar to a procedure, but it returns a single value. Its definition states the data type of the value that will be returned.

Cambridge pseudocode function with parameters:

FUNCTION CalculateArea(Length : INTEGER, Width : INTEGER) RETURNS INTEGER\n  RETURN Length * Width\nENDFUNCTION

A function call is used as part of an expression. Do not use CALL when calling a function.

Area ← CalculateArea(8, 5)\nOUTPUT Area

CalculateArea(8, 5) returns 40. This returned value is used in the assignment to Area.

A function without parameters is also possible:

FUNCTION GetPassMark RETURNS INTEGER\n  RETURN 50\nENDFUNCTION\n\nOUTPUT GetPassMark
The RETURN statement specifies the value sent back by the function. The returned value must match the data type stated after RETURNS.

5. Procedure or function?

Choose a procedure when the main purpose is to carry out an action, such as displaying a message. Choose a function when a value is needed for use in an expression, such as calculating and returning an area.

6. Local and global variables

A local variable is declared inside a procedure or function. It is available only within that procedure or function. It cannot be accessed directly by the main program or by other subprograms.

A global variable is declared outside procedures and functions. It can be accessed by the main program and by procedures or functions, subject to the rules of the programming language.

Example of a local variable:

PROCEDURE ShowSquare(Number : INTEGER)\n  DECLARE Result : INTEGER\n  Result ← Number * Number\n  OUTPUT Result\nENDPROCEDURE

Result is local to ShowSquare. The main program cannot use Result directly outside the procedure.

Example of a global variable:

DECLARE SchoolName : STRING\nSchoolName ← "MES Cairo"\n\nPROCEDURE DisplaySchool\n  OUTPUT SchoolName\nENDPROCEDURE\n\nCALL DisplaySchool

SchoolName is declared outside the procedure, so it is global in this example. Using parameters and local variables where suitable can reduce unwanted dependence on global data.

7. Python 3 comparison

Python uses def to define both procedures and functions. A Python function that does not explicitly return a value returns None.

Python procedure-style function:

def display_welcome():\n print("Welcome to the program")\n\ndisplay_welcome()

Python function with parameters and a returned value:

def calculate_area(length, width):\n return length * width\n\narea = calculate_area(8, 5)\nprint(area)

Python local variable:

def show_square(number):\n result = number * number\n print(result)

The variable result is local to show_square. Python also supports global variables, but the global keyword is needed if a function assigns to a global variable. For this chapter, focus on understanding scope rather than using global variables unnecessarily.

8. Common mistakes

Using CALL with a function. Cambridge functions are used as part of an expression.

Forgetting RETURN in a function that must return a value.

Omitting the return data type after RETURNS in a Cambridge function definition.

Confusing a parameter in a definition with an argument supplied in a call.

Supplying arguments in the wrong order or using an incompatible data type.

Trying to access a local variable outside the procedure or function where it is declared.

Writing more than three parameters when the Cambridge syllabus limits the required number to three.

Key points to remember

Procedures and functions are named sections of reusable code.

A procedure performs a task and is called using CALL.

A function returns a single value and is used as part of an expression; do not use CALL.

Parameters are named in the definition; arguments are supplied in the call.

A function uses RETURNS to state the data type and RETURN to send back its value.

Local variables are available only within the subprogram where they are declared.

Global variables are declared outside subprograms and can be accessed from other parts of the program.

The Cambridge 0984 syllabus allows up to three parameters.
