Explain why a program needs input and output.

Use OUTPUT to display values and messages.

1. Input and output

A program often needs data from a user or another source. It may also need to display information so that the user can see the result.

Input allows a program to receive data. Output allows a program to communicate information or results.

2. INPUT in Cambridge-style pseudocode

The INPUT command receives a value and stores it in the variable named after INPUT.
INPUT Answer

In this example, the value entered is stored in the variable Answer. The variable must be declared and must be suitable for the value being entered.

DECLARE LearnerName : STRING
DECLARE Score : INTEGER

INPUT LearnerName
INPUT Score

The program receives a name and a score. The first value is stored as a string and the second as an integer.

The Cambridge pseudocode format is:

INPUT <identifier>

The identifier can be a variable. It can also be an individual element of a data structure, such as an array element.

3. OUTPUT in Cambridge-style pseudocode

The OUTPUT command displays a value, the contents of a variable, or a message.
OUTPUT Score
OUTPUT "Welcome to the program"

The first statement displays the value stored in Score. The second displays the text message.

The Cambridge pseudocode format is:

OUTPUT <value(s)>
Several values can be displayed using one OUTPUT statement. Separate the values with commas.
OUTPUT "Learner: ", LearnerName, " Score: ", Score

This displays text and variable values together in one output statement.

4. A simple input-process-output program

Problem: Ask the user to enter two numbers, calculate their total and display the answer.

Cambridge-style pseudocode:

DECLARE FirstNumber : REAL
DECLARE SecondNumber : REAL
DECLARE Total : REAL

INPUT FirstNumber
INPUT SecondNumber

Total ← FirstNumber + SecondNumber

OUTPUT "The total is ", Total

The program receives two values, adds them, and displays the result. This follows the sequence input, process and output.

5. Python 3 input and output

Python uses input() to receive data from the user and print() to display output.

name = input("Enter your name: ")
print("Welcome", name)

The text inside input() is a prompt. The value entered by the user is returned as a string and stored in name.

If a program needs a number for a calculation, convert the input string to a numeric type.

first_number = int(input("Enter the first whole number: "))
second_number = int(input("Enter the second whole number: "))

total = first_number + second_number
print("The total is", total)

Use int() when a whole number is required and float() when a number may contain a decimal part.

temperature = float(input("Enter the temperature: "))
print("Temperature:", temperature)

Python print() can display several values separated by commas. Python automatically places a space between the displayed items by default.

6. Cambridge pseudocode and Python compared

Do not mix the two forms. INPUT and OUTPUT are Cambridge pseudocode commands. input() and print() are Python functions.

7. Worked examples

Example 1: Read and display a name

DECLARE Name : STRING
INPUT Name
OUTPUT "Hello, ", Name

The program receives a name and displays a greeting.

Example 2: Calculate the area of a rectangle

DECLARE Length : REAL
DECLARE Width : REAL
DECLARE Area : REAL

INPUT Length
INPUT Width
Area ← Length * Width
OUTPUT "Area: ", Area

The program receives the length and width, calculates the area, and displays the result.

Example 3: Display two values in one statement

DECLARE Subject : STRING
DECLARE Mark : INTEGER

INPUT Subject
INPUT Mark
OUTPUT "Subject: ", Subject, " Mark: ", Mark
A single OUTPUT statement displays both variables together with explanatory text.

8. Quick check

1. Which Cambridge pseudocode command receives a value?

Answer: INPUT.

2. Which Cambridge pseudocode command displays information?

Answer: OUTPUT.

3. What does INPUT Score do?

Answer: It receives a value and stores it in Score.

4. Can one OUTPUT statement display several values?

Answer: Yes. Separate the values with commas.

5. What does Python input() return?

Answer: A string.

6. Which Python conversion is suitable for a whole number?

Answer: int().

7. Which Python function displays information?

Answer: print().

OUTPUT displays a value or message.
INPUT Age
OUTPUT "Total: ", Total
DECLARE FirstNumber : INTEGER; DECLARE SecondNumber : INTEGER; DECLARE Difference : INTEGER; INPUT FirstNumber; INPUT SecondNumber; Difference ← FirstNumber - SecondNumber; OUTPUT Difference.

Python input() returns a string. Convert it to int or float before carrying out numeric arithmetic.

number = int(input("Enter a whole number: ")); print(number * 2)

Remember these key points

Input is data supplied to a program; output is information produced by a program.

Cambridge pseudocode uses INPUT followed by a variable identifier.
Cambridge pseudocode uses OUTPUT followed by one or more values.
Several values can be displayed in one OUTPUT statement, separated by commas.

Python uses input() to receive data and print() to display it.

Python input() returns a string; convert it when a numeric value is needed.

Keep Cambridge pseudocode and Python syntax separate.
