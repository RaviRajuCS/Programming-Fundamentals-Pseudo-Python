1. What is string handling?

A string is a sequence of characters. String handling means performing operations on strings, such as finding their length, extracting part of a string, or changing characters to uppercase or lowercase.

Cambridge IGCSE 0984 (2026–2028) specifies four string operations: LENGTH, SUBSTRING, UCASE and LCASE. These are the operations covered in this chapter.

2. LENGTH – finding the number of characters

LENGTH returns an integer representing the number of characters in a string. Spaces and punctuation are counted as characters.

Cambridge pseudocode syntax:

LENGTH(<identifier>)

Worked example:

DECLARE Message : STRING\nMessage ← "Happy Days"\nOUTPUT LENGTH(Message)

Output: 10. The space between “Happy” and “Days” is included in the count.

The identifier supplied to LENGTH must be a STRING.

3. SUBSTRING – extracting part of a string

SUBSTRING returns part of a string. You specify the string identifier, the starting position and the number of characters to return.

Cambridge pseudocode syntax:

SUBSTRING(<identifier>, <start>, <length>)

Worked example (using position 1 for the first character):

DECLARE Word : STRING\nWord ← "Computer"\nOUTPUT SUBSTRING(Word, 1, 3)

Output: "Com". The operation starts at position 1 and returns 3 characters.

Important details:

The start position identifies where extraction begins.

The length specifies how many characters are returned.

The start and length arguments must be positive integers in the Cambridge specification.

The first character can be at position 0 or position 1. In the example above, position 1 is used. Always follow the indexing convention stated in the question or example.

4. UCASE – converting to uppercase

UCASE returns a string or character with all letters converted to uppercase. It does not change the original identifier unless the returned value is assigned back to it.

Cambridge pseudocode syntax:

UCASE(<identifier>)

Worked example:

DECLARE Name : STRING\nName ← "Ravi"\nOUTPUT UCASE(Name)

Output: "RAVI". The identifier supplied can be STRING or CHAR.

5. LCASE – converting to lowercase

LCASE returns a string or character with all letters converted to lowercase.

Cambridge pseudocode syntax:

LCASE(<identifier>)

Worked example:

DECLARE Letter : CHAR\nLetter ← "W"\nOUTPUT LCASE(Letter)

Output: "w". The identifier supplied can be STRING or CHAR.

6. Using the returned value

A string operation returns a value. You can display that value or assign it to a variable of a suitable data type.

DECLARE Original : STRING\nDECLARE NewText : STRING\nOriginal ← "Cambridge"\nNewText ← UCASE(Original)\nOUTPUT NewText

NewText stores "CAMBRIDGE". Original remains "Cambridge" because the result was assigned to NewText.

7. Python 3 comparison

Python provides built-in string operations with different names and syntax. These Python methods are useful comparisons, but Cambridge pseudocode syntax must be used when the question asks for pseudocode.

Python example:

text = "Happy Days"\nprint(len(text)) # 10\nprint(text.upper()) # HAPPY DAYS\nprint(text.lower()) # happy days\nprint(text[0:5]) # Happy

Python uses zero-based indexing. Its slice end position is excluded. The slice text[0:5] returns five characters starting from the first character.

8. Common mistakes

Forgetting that LENGTH counts spaces and punctuation.

Confusing the start position with the number of characters to return in SUBSTRING.

Using a non-integer value for the SUBSTRING start or length.

Assuming the first character is always at position 0; Cambridge allows position 0 or 1.

Writing Python method syntax in a Cambridge pseudocode answer.

Assuming UCASE or LCASE changes the original variable when the returned value has not been assigned back.

10. Cambridge-style exam practice

A program stores a user’s input in a string variable called UserName. Assume the first character is at position 1.

(a) Write a statement to output the number of characters in UserName. [1]

(b) Write a statement to output UserName in uppercase. [1]

(c) Write a statement to output the first three characters of UserName. [2]

(d) The user enters "MES Cairo". State the value returned by LENGTH(UserName). [1]

(e) Explain the purpose of the length argument in SUBSTRING. [2]

Key points to remember

LENGTH returns the number of characters in a string, including spaces.

SUBSTRING returns a specified number of characters starting at a specified position.

UCASE returns uppercase characters.

LCASE returns lowercase characters.

The first character position can be 0 or 1; follow the convention used in the question.

Python uses len(), upper(), lower() and slicing, not Cambridge pseudocode function names.
