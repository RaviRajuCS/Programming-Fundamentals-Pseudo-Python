IGCSE PROGRAMMING FOUNDATIONS — OFFLINE WEBSITE
================================================

Contents:
- index.html: chapter hub
- T01-P01.html through T14-P01.html: individual chapter webpages

How to use:
1. Extract the ZIP file.
2. Keep all HTML files together in the same folder.
3. Double-click index.html to open the hub in a modern browser.
4. Internet access is not required.

Features:
- 14 self-contained chapter pages
- Embedded CSS and JavaScript
- Responsive glassmorphic interface and buttons
- Chapter navigation
- Source chapter explanations, examples, pseudocode, Python comparisons and tables
- Copy-code buttons
- Three-question interactive knowledge check per chapter with instant feedback
- Print / Save as PDF

The pages are based on the 14 supplied IGCSE Programming Foundations student-edition documents. Review the content against the current Cambridge syllabus and your teaching sequence before classroom publication.
