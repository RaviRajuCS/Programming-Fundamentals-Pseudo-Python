1. Why use files?

A file stores data so that it can be used by a program later. Unlike data held only in variables while a program is running, information saved in a file can remain available after the program ends.

Examples include storing student names and marks, saving a list of products, or keeping a set of text records. Cambridge IGCSE 0984 requires candidates to understand the purpose of storing data in a file and to open, close, read and write files.

2. Opening a file

Before a program can read from or write to a file, it should open the file and state the mode of operation.

Cambridge pseudocode syntax:

OPENFILE <File identifier> FOR <File mode>

The file identifier is the file name, which has the data type STRING. Cambridge specifies two file modes:

Example:

OPENFILE "Students.txt" FOR READ\nOPENFILE "Results.txt" FOR WRITE

A file should be opened in only one mode at a time. Do not open the same file for reading and writing simultaneously using these modes.

3. Reading data from a file

After opening a file in READ mode, use READFILE to read a data item and assign it to a variable.

Cambridge pseudocode syntax:

READFILE <File identifier>, <Variable>

Worked example: read one line of text from a file.

DECLARE StudentName : STRING\nOPENFILE "Students.txt" FOR READ\nREADFILE "Students.txt", StudentName\nOUTPUT StudentName\nCLOSEFILE "Students.txt"
The READFILE command reads the next data item from the file and assigns it to StudentName. In this example, the variable is a STRING because the program is reading a student name.

4. Writing data to a file

After opening a file in WRITE mode, use WRITEFILE to write a variable or data item to the file.

Cambridge pseudocode syntax:

WRITEFILE <File identifier>, <Variable>

Worked example: write a student name to a file.

DECLARE StudentName : STRING\nStudentName ← "Amina"\nOPENFILE "Students.txt" FOR WRITE\nWRITEFILE "Students.txt", StudentName\nCLOSEFILE "Students.txt"

The value stored in StudentName is written to the file. Remember: opening a file in WRITE mode creates a new file or overwrites the existing contents.

5. Closing a file

When a program has finished using a file, it should close it. Cambridge pseudocode uses CLOSEFILE.

CLOSEFILE <File identifier>

Closing a file indicates that the program has finished using it. It is good practice to close every file that has been opened, once the required reading or writing is complete.

6. Complete example – copying a line of text

This example follows the file-handling example in the Cambridge syllabus. It reads a line from one file and writes that line to another file.

DECLARE LineOfText : STRING\nOPENFILE "FileA.txt" FOR READ\nOPENFILE "FileB.txt" FOR WRITE\nREADFILE "FileA.txt", LineOfText\nWRITEFILE "FileB.txt", LineOfText\nCLOSEFILE "FileA.txt"\nCLOSEFILE "FileB.txt"

Step by step:

LineOfText is declared as a STRING.

FileA.txt is opened in READ mode.

FileB.txt is opened in WRITE mode.

One line of text is read from FileA.txt into LineOfText.

The value of LineOfText is written to FileB.txt.

Both files are closed.

7. Reading and writing several items

If the number of data items is known, iteration can be used to read or write them one at a time. The following example reads five names from a file. It assumes that the file contains at least five items.

DECLARE Name : STRING\nOPENFILE "Names.txt" FOR READ\nFOR Count ← 1 TO 5\n  READFILE "Names.txt", Name\n  OUTPUT Name\nNEXT Count\nCLOSEFILE "Names.txt"
The loop executes READFILE five times. Each execution reads the next item. The file is closed after the five items have been read.
This example uses a known number of items. Do not assume an end-of-file command or syntax unless it is provided in the question or taught from an authorised specification: the Cambridge 0984 pseudocode file-handling guidance lists OPENFILE, READFILE, WRITEFILE and CLOSEFILE.

8. Python 3 comparison

Python uses open() to open a file. The mode "r" is used for reading and "w" is used for writing. The with statement is a common Python method because it closes the file automatically when the block finishes.

Reading one line:

with open("Students.txt", "r") as file:\n student_name = file.readline()\n print(student_name)

Writing text:

with open("Students.txt", "w") as file:\n file.write("Amina")

Important Python comparison:

Python "r" corresponds to Cambridge READ.

Python "w" corresponds to Cambridge WRITE and overwrites existing file contents.

Python file.readline() reads a line of text.

Python file.write() writes text to a file.

Python close() closes a file when using open() without with. The with statement closes it automatically.

The Python examples are comparisons. In Cambridge pseudocode examination answers, use the Cambridge commands and syntax.

9. Common mistakes

Trying to read from a file that has not been opened in READ mode.

Trying to write to a file that has not been opened in WRITE mode.

Forgetting that WRITE mode removes existing file contents.

Using READFILE without specifying the variable that receives the data.
Using WRITEFILE without identifying the data to be written.

Forgetting to close a file after using it.

Using Python file methods in a Cambridge pseudocode answer.

Key points to remember

Files store data so that it can be used by a program later.

OPENFILE opens a file and specifies READ or WRITE mode.
READFILE reads the next data item and assigns it to a variable.
WRITEFILE writes a data item or variable to a file.
CLOSEFILE closes a file when it is no longer needed.

WRITE mode creates a new file or overwrites existing contents.

A file should be opened in only one mode at a time.

Cambridge file handling requires reading and writing single items and lines of text.
