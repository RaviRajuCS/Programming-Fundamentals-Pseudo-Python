1. What is iteration?

Iteration is the repeated execution of a statement or group of statements. The repeated instructions are called a loop. Iteration avoids writing the same instructions many times.

A loop must have a clear stopping condition or end point. If it never reaches that point, an infinite loop may occur.

2. Count-controlled iteration – FOR loop

A FOR loop is used when the number of repetitions is known or controlled by a counter. The loop variable takes each integer value from the start value to the end value, inclusive.

Cambridge pseudocode:

FOR <identifier> ← <value1> TO <value2>\n  <statements>\nNEXT <identifier>

A STEP value can change the increment. It must evaluate to an integer and can be negative.

FOR <identifier> ← <value1> TO <value2> STEP <increment>\n  <statements>\nNEXT <identifier>

Worked example: Display the numbers 1 to 5.

FOR Count ← 1 TO 5\n  OUTPUT Count\nNEXT Count

The output is 1, 2, 3, 4, 5. The loop runs five times. If the start value equals the end value, it runs once. If the start value is greater than the end value, it does not run (with the default positive step).

3. Pre-condition iteration – WHILE loop

A WHILE loop checks its condition before executing the loop statements. The statements execute only while the condition is TRUE. If the condition is FALSE at the first check, the loop body does not execute at all.

Cambridge pseudocode:

WHILE <condition> DO\n  <statements>\nENDWHILE

Worked example: Display 1 to 5.

Count ← 1\nWHILE Count <= 5 DO\n  OUTPUT Count\n  Count ← Count + 1\nENDWHILE

The counter is increased inside the loop. When Count becomes 6, the condition is FALSE and the loop ends.

4. Post-condition iteration – REPEAT UNTIL loop

A REPEAT UNTIL loop checks its condition after executing the loop statements. Therefore, the statements always execute at least once. The loop repeats while the condition is FALSE and stops when the condition becomes TRUE.

Cambridge pseudocode:

REPEAT\n  <statements>\nUNTIL <condition>

Worked example: Ask for a password until the correct password is entered.

REPEAT\n  OUTPUT "Enter password"\n  INPUT Password\nUNTIL Password = "Secret"

The password is checked after each input. Even if the first input is correct, the prompt and input happen once.

6. Python 3 comparison

Python uses for with range() for count-controlled loops. The final value in range() is not included.

for count in range(1, 6):\n print(count)

A Python while loop repeats while its condition is TRUE:

count = 1\nwhile count <= 5:\n print(count)\n count = count + 1

Python has no direct REPEAT UNTIL statement. A similar behaviour can be created with while True and break, but this is an additional Python technique rather than Cambridge pseudocode.

while True:\n password = input("Enter password: ")\n if password == "Secret":\n break

For this course, learn the Cambridge REPEAT ... UNTIL structure accurately. The Python example is only to show one way to achieve the same behaviour.

7. Trace a loop

Trace tables help you follow how variable values change during iteration. Consider this pseudocode:

Total ← 0\nFOR Number ← 1 TO 4\n  Total ← Total + Number\nNEXT Number\nOUTPUT Total

The values added are 1, 2, 3 and 4. The final value of Total is 10.

8. Common mistakes

Forgetting to update a counter in a WHILE loop, which may create an infinite loop.
Using the wrong condition in REPEAT UNTIL: the loop stops when the condition becomes TRUE.
Assuming WHILE and REPEAT UNTIL always execute at least once. Only REPEAT UNTIL guarantees one execution.
Forgetting that the FOR loop end value is included in Cambridge pseudocode.

Forgetting that Python range() excludes its stop value.

Key points to remember

Iteration repeats a set of instructions.

FOR is count-controlled; the end value is included in Cambridge pseudocode.
WHILE tests before the loop body, so the body may execute zero times.
REPEAT UNTIL tests after the loop body, so the body executes at least once.

Make sure loop variables and conditions change so that the loop can terminate.

Python range() excludes its stop value; Python does not have a direct REPEAT UNTIL statement.
