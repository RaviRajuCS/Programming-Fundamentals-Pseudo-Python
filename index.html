How to use this hub

  1. Open chapters in sequence, starting with Chapter 1.
  2. Read each explanation and examine the worked examples carefully.
  3. Trace pseudocode by hand and compare with Python where provided.
  4. Complete the three-question knowledge check and read the feedback.
  5. Use the chapter navigation to move forward or revisit earlier concepts.

This is a self-contained offline website. Keep the HTML files together in the same folder so chapter links work.
