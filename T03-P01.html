1. What is an operator?

An operator is a symbol or word that tells a program to perform an operation. An expression combines values, variables and operators to produce a result.

Total ← Price * Quantity

In this expression, * is the operator. Price and Quantity are values or variables. The expression calculates their product.

2. Arithmetic operators

Arithmetic operators perform mathematical calculations. These are the arithmetic operators required by Cambridge IGCSE 0984.

Remember the difference between DIV and MOD:

DIV gives the whole-number quotient.

MOD gives the remainder.

Example: 17 divided by 5 gives a quotient of 3 and a remainder of 2.

DIV(17, 5) = 3
MOD(17, 5) = 2

Cambridge pseudocode writes DIV and MOD in function form, with the two integer operands inside brackets.

3. Relational operators

Relational operators compare two values. The result of a relational operation is always a BOOLEAN value: TRUE or FALSE.

Example: A school considers a score of 50 or more a pass.

Score >= 50

If Score is 65, the expression is TRUE. If Score is 42, the expression is FALSE.

4. Logical operators

Logical operators work with Boolean values or conditions. Cambridge IGCSE uses AND, OR and NOT.

Examples:

(Score >= 50) AND (Attendance >= 80)
(Temperature > 30) OR (Humidity > 70)
NOT (PasswordValid = TRUE)

The first expression is TRUE only when the score is at least 50 AND attendance is at least 80. The second is TRUE when either condition, or both, is TRUE. The third reverses the result of the condition.

5. Using operators in expressions

A program often combines arithmetic and relational operators to make a decision.

Example: calculate a total price and check whether it is within a budget.

TotalCost ← Price * Quantity
WithinBudget ← TotalCost <= Budget

The first expression calculates a number. The second compares two values and produces TRUE or FALSE.

Use brackets to make the intended order of operations clear, especially in longer expressions. Cambridge specifies that multiplication and division have higher precedence than addition and subtraction. Brackets are recommended when an expression could be misunderstood.

Result ← (A + B) * C
Result ← A + (B * C)

These expressions may produce different answers. If A = 2, B = 3 and C = 4, the first gives 20 and the second gives 14.

Important differences:

In Cambridge pseudocode, = is used for equality in a condition. In Python, == is used for equality; = is used for assignment.

Cambridge uses ^ for powers. Python uses ** for powers; ^ in Python is a different operator and must not be used for exponentiation.

Cambridge uses <> for not equal. Python uses !=.

Python uses and, or and not in lowercase.

Python // is shown here for positive integer operands. Do not assume its behaviour for negative numbers is identical to every integer-division convention.

7. Worked examples

Example 1: Calculate the average

Total ← Mark1 + Mark2 + Mark3
Average ← Total / 3

The first expression adds the three marks. The second divides the total by 3.

Example 2: Check a valid mark

IF (Mark >= 0) AND (Mark <= 100) THEN
    OUTPUT "Valid mark"
ELSE
    OUTPUT "Invalid mark"
ENDIF

A mark is valid only when both conditions are TRUE.

Example 3: Check whether a number is odd

IF MOD(Number, 2) <> 0 THEN
    OUTPUT "ODD"
ELSE
    OUTPUT "EVEN"
ENDIF

A number is odd when the remainder after division by 2 is not zero.

8. Quick check

1. What is the result of 9 * 4?

Answer: 36.

2. What is DIV(17, 5)?

Answer: 3.

3. What is MOD(17, 5)?

Answer: 2.

4. Which relational operator means not equal to in Cambridge pseudocode?

Answer: <>.

5. What is the result of 8 >= 10?

Answer: FALSE.

6. When is A AND B TRUE?

Answer: Only when both A and B are TRUE.

7. What does NOT do?

Answer: It reverses a Boolean value.

9. Cambridge-style practice

Evaluate each expression: (a) 12 + 5 * 2 (b) DIV(23, 4) (c) MOD(23, 4). (3 marks)

State the result of each comparison: (a) 9 < 4 (b) 6 >= 6 (c) 12 <> 12. (3 marks)

Explain the difference between DIV and MOD. (2 marks)

State the condition under which A OR B is FALSE. (1 mark)

Write a Cambridge-style expression that is TRUE when Age is at least 13 and less than 17. (2 marks)

A learner passes if Score is at least 50 OR the learner has been awarded a special pass. Write a logical expression for this rule. (2 marks)

Write an expression to calculate the square of Number and add 10 to the result. (1 mark)

State the Python operator for exponentiation and explain why ^ should not be used for this purpose in Python. (2 marks)

Suggested answers

(a) 22 (b) 5 (c) 3.

(a) FALSE (b) TRUE (c) FALSE.

DIV returns the quotient with the fractional part discarded; MOD returns the remainder.

A OR B is FALSE only when both A and B are FALSE.

(Age >= 13) AND (Age < 17).

(Score >= 50) OR (SpecialPass = TRUE).

(Number ^ 2) + 10.

Python uses ** for exponentiation. ^ is a different Python operator (bitwise XOR), not the power operator.

Remember these key points

Arithmetic operators calculate values: +, -, *, /, ^, DIV and MOD.

DIV returns the integer quotient; MOD returns the remainder.

Relational operators compare values and return TRUE or FALSE.

Cambridge relational operators are =, <, <=, >, >= and <>.

Logical operators are AND, OR and NOT.

Use brackets to make complex expressions clear.

Do not confuse Cambridge pseudocode symbols with Python operators.
