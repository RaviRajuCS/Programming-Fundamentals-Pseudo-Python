1. What are totalling and counting?

Totalling means adding a series of values to produce a total. Counting means keeping track of how many times something happens or how many items meet a condition. Both are commonly used with iteration.

A variable used to store a running total is often called a total or accumulator. A variable used to keep track of a number of occurrences is called a counter.

2. Totalling – using an accumulator

An accumulator stores a running total. It must be initialised before the loop. Each new value is added to the current total.

Worked example: input five numbers and calculate their total.

Total ← 0\nFOR Count ← 1 TO 5\n  INPUT Number\n  Total ← Total + Number\nNEXT Count\nOUTPUT Total

Why does this work?

Total ← 0 gives the accumulator a starting value.
The FOR loop repeats five times.

Each input value is added to the previous value of Total.

After the loop, Total contains the sum of all five numbers.

3. Counting – using a counter

A counter keeps track of how many times an event occurs. It is usually initialised to zero and increased by one each time the event happens.

Worked example: input five numbers and count how many are positive.

PositiveCount ← 0\nFOR Count ← 1 TO 5\n  INPUT Number\n  IF Number > 0\n  THEN\n    PositiveCount ← PositiveCount + 1\n  ENDIF\nNEXT Count\nOUTPUT PositiveCount

The counter increases only when Number > 0 is TRUE. Numbers that are zero or negative do not increase PositiveCount.

4. Totalling values that meet a condition

Selection can be placed inside a loop so that only values meeting a condition are added to the total.

Worked example: input five marks and calculate the total of marks that are 50 or above.

PassTotal ← 0\nFOR Count ← 1 TO 5\n  INPUT Mark\n  IF Mark >= 50\n  THEN\n    PassTotal ← PassTotal + Mark\n  ENDIF\nNEXT Count\nOUTPUT PassTotal

Only marks of 50 or more are added. A mark below 50 is ignored for this total.

5. Counting and totalling together

An algorithm can use both a counter and an accumulator. For example, it can calculate the total of passing marks and count how many students passed.

PassTotal ← 0\nPassCount ← 0\nFOR Index ← 1 TO 5\n  INPUT Mark\n  IF Mark >= 50\n  THEN\n    PassTotal ← PassTotal + Mark\n    PassCount ← PassCount + 1\n  ENDIF\nNEXT Index\nOUTPUT "Number of passes: ", PassCount\nOUTPUT "Total of passing marks: ", PassTotal

Both variables are initialised before the loop. When a mark is at least 50, the algorithm updates both the total and the count.

6. Trace table example

Consider the following input values: 12, -3, 8, 0, 5. The algorithm counts positive values and calculates their total.

Total ← 0\nPositiveCount ← 0\nFOR Index ← 1 TO 5\n  INPUT Number\n  IF Number > 0\n  THEN\n    Total ← Total + Number\n    PositiveCount ← PositiveCount + 1\n  ENDIF\nNEXT Index

Final values: Total = 25 and PositiveCount = 3.

7. Python 3 comparison

Python uses the same ideas. A variable is initialised before the loop, then updated during each repetition.

Totalling five entered numbers:

total = 0\nfor count in range(5):\n number = int(input("Enter a number: "))\n total = total + number\nprint(total)

Counting positive numbers:

positive_count = 0\nfor count in range(5):\n number = int(input("Enter a number: "))\n if number > 0:\n positive_count = positive_count + 1\nprint(positive_count)

The Python variable names are written in lowercase as a common Python style. Cambridge pseudocode uses its own identifier conventions; keep the two notations separate.

8. Common mistakes

Forgetting to initialise a total or counter before the loop.

Initialising the total inside the loop, which resets it on every repetition.

Increasing a counter when the condition is FALSE.

Adding a value to the total when it should not meet the required condition.

Using Total ← Total + 1 when the task requires adding the input value.

Confusing the loop variable, which controls repetition, with a counter that records occurrences.

Key points to remember

A total or accumulator adds values together and stores a running sum.

A counter records how many times an event occurs.

Initialise totals and counters before the loop.

Update the accumulator by adding the value; update a counter by adding 1.

Use IF inside a loop when only values meeting a condition should be counted or totalled.

Use a trace table to follow the changing values of totals and counters.
