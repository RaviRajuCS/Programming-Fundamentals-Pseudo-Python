1. What is a nested statement?

A nested statement is a control structure placed inside another control structure. For example, an IF statement can be placed inside a FOR loop, or one IF statement can be placed inside another IF statement.

Nesting is useful when a program must make a decision within a repeated process, or when one decision depends on the result of another decision.

Cambridge syllabus requirement: candidates should understand and use nested statements, including nested selection and iteration. Candidates will not be required to write more than three levels of nested statements.

2. Nested IF statements

A nested IF is an IF statement placed inside another IF statement. The inner decision is reached only when the outer condition allows the program to enter that branch.

Worked example: classify a mark as Fail, Pass or Distinction.

IF Mark >= 50\nTHEN\n  IF Mark >= 80\n  THEN\n    OUTPUT "Distinction"\n  ELSE\n    OUTPUT "Pass"\n  ENDIF\nELSE\n  OUTPUT "Fail"\nENDIF

How it works:

If Mark is below 50, the outer ELSE displays “Fail”.

If Mark is at least 50, the inner IF is checked.

If Mark is at least 80, “Distinction” is displayed; otherwise “Pass” is displayed.

For Mark = 75, the output is “Pass”. For Mark = 86, the output is “Distinction”.

3. Selection inside a loop

An IF statement can be placed inside a loop to make a decision for each value processed by the loop.

Worked example: input five marks and count how many are passes.

PassCount ← 0\nFOR Index ← 1 TO 5\n  INPUT Mark\n  IF Mark >= 50\n  THEN\n    PassCount ← PassCount + 1\n  ENDIF\nNEXT Index\nOUTPUT PassCount
The FOR loop processes five marks. For each mark, the IF statement checks whether it is at least 50. The counter increases only for a pass.

4. Iteration inside selection

A loop can also be placed inside an IF branch. The loop runs only when the condition is TRUE.

Worked example: if the user confirms that a report is required, display five report headings.

IF ReportRequired = TRUE\nTHEN\n  FOR Item ← 1 TO 5\n    OUTPUT "Report section ", Item\n  NEXT Item\nELSE\n  OUTPUT "No report required"\nENDIF
If ReportRequired is FALSE, the FOR loop is skipped completely.

5. Nested iteration

Nested iteration means placing one loop inside another loop. It is commonly used to process two-dimensional data, such as rows and columns in a 2D array.

Worked example: output all elements in an array containing three rows and four columns.

FOR Row ← 1 TO 3\n  FOR Column ← 1 TO 4\n    OUTPUT Data[Row, Column]\n  NEXT Column\nNEXT Row

The inner loop completes all four columns for the current row. Then the outer loop moves to the next row. The inner loop runs 3 × 4 = 12 times in total.

6. Combining nested loops with selection

A selection statement can be placed inside nested loops. This allows an algorithm to check every element and perform an action only when an element meets a condition.

Worked example: count how many values in a 2D array are greater than 50.

Count ← 0\nFOR Row ← 1 TO 3\n  FOR Column ← 1 TO 4\n    IF Data[Row, Column] > 50\n    THEN\n      Count ← Count + 1\n    ENDIF\n  NEXT Column\nNEXT Row\nOUTPUT Count
For each row and column, the IF statement checks one array element. Count increases only when the value is greater than 50.

7. Understanding the levels of nesting

A level of nesting is a control structure placed inside another control structure. In the following example, the IF statement is inside a FOR loop, so it is one level of nesting:
FOR Index ← 1 TO 5\n  IF Number[Index] > 0\n  THEN\n    OUTPUT Number[Index]\n  ENDIF\nNEXT Index
In the next example, an IF statement is inside a FOR loop, which is inside another FOR loop. This has two nested levels:
FOR Row ← 1 TO 3\n  FOR Column ← 1 TO 4\n    IF Data[Row, Column] > 50\n    THEN\n      OUTPUT Data[Row, Column]\n    ENDIF\n  NEXT Column\nNEXT Row

Keep the structure readable. Cambridge states that candidates will not be required to write more than three levels of nested statements.

8. Python 3 comparison

Python uses indentation to show which statements belong inside each control structure. Each nested block is indented further.

Nested IF:

if mark >= 50:\n if mark >= 80:\n print("Distinction")\n else:\n print("Pass")\nelse:\n print("Fail")

Selection inside a loop:

pass_count = 0\nfor index in range(5):\n mark = int(input("Enter mark: "))\n if mark >= 50:\n pass_count = pass_count + 1\nprint(pass_count)

Nested iteration:

for row in range(3):\n for column in range(4):\n print(data[row][column])

Python does not use ENDIF, NEXT or ENDWHILE. Indentation defines the blocks.

9. Common mistakes

Incorrect indentation that makes a statement belong to the wrong IF or loop.
Placing ENDIF or NEXT at the wrong level in Cambridge pseudocode.
Updating a counter outside the IF condition when it should only count matching values.

Forgetting that the inner loop completes all its repetitions before the outer loop advances.

Using the row and column indexes in the wrong order.

Creating unnecessary nesting that makes an algorithm difficult to follow.

(b) Modify the algorithm so that it counts the number of marks greater than or equal to 50. [3]

(c) Write a nested IF statement to classify a mark as “Distinction” (80 or more), “Pass” (50 to 79), or “Fail” (below 50). [4]

Key points to remember

A nested statement is a control structure inside another control structure.

Nested IF statements allow a decision to be made within another decision.

Selection inside a loop checks each value processed by the loop.

Nested loops are useful for processing rows and columns in 2D arrays.

The inner loop completes its repetitions before the outer loop advances.

Cambridge limits required written nesting to no more than three levels.

Indentation and matching ENDIF/NEXT statements are essential for clarity.
