1. What is programming?

Programming is the process of creating instructions that a computer can follow to solve a problem or complete a task. A programmer first understands the problem, plans a solution, writes the instructions, and checks that the solution works.

A computer program is a set of instructions written in a programming language. In this book, you will learn to express algorithms using Cambridge-style pseudocode and practise programming using Python.

2. What is an algorithm?

An algorithm is a finite sequence of clear steps used to solve a problem. It describes the logic of the solution without depending on a particular programming language.

A good algorithm should:

Be clear: each instruction has one understandable meaning.

Be in the correct order: steps must be arranged logically.

Finish: it must not continue forever.

Produce the required result for the given valid input.

Worked example: Calculate the area of a rectangle

Problem: The user enters the length and width of a rectangle. The program calculates and displays its area.

Algorithm in plain English:

Get the length.

Get the width.

Multiply the length by the width.

Display the area.

Cambridge-style pseudocode:

DECLARE Length : REAL
DECLARE Width : REAL
DECLARE Area : REAL

INPUT Length
INPUT Width

Area ← Length * Width

OUTPUT Area

Equivalent Python 3:

length = float(input("Enter length: "))
width = float(input("Enter width: "))

area = length * width
print("Area:", area)

Remember: pseudocode explains the algorithm in a structured, language-independent form. Python is a real programming language that can be run by a computer.

3. Developing a program

A program is usually developed in stages. These stages help the programmer move from understanding a problem to producing a tested solution.

The stages are linked. Testing may reveal a problem that requires the programmer to return to the design or coding stage. Program development is therefore often iterative.

4. Abstraction

Abstraction means removing details that are not needed and concentrating on the information that matters for the problem.

Example: A program calculates the average of three examination marks. It needs the three marks. It does not need the student's home address, telephone number or favourite sport.

The programmer has focused on the relevant information. This is abstraction.

5. Decomposition

Decomposition means breaking a large problem into smaller parts that are easier to understand, design and solve.

Example: A program calculates a student's average and decides whether the student has passed.

Each part has a clear purpose. The smaller parts can be planned and checked more easily than one large, complicated solution.

6. Identify input, process and output

A useful first step when analysing a problem is to identify:

Input: the data entered or supplied to the program.

Process: the calculation or action performed using the data.

Output: the information produced by the program.

7. A simple algorithm with a decision

Problem: Read an integer and display EVEN if it is divisible by 2; otherwise display ODD.

Cambridge-style pseudocode:

DECLARE Number : INTEGER

INPUT Number

IF Number MOD 2 = 0 THEN
    OUTPUT "EVEN"
ELSE
    OUTPUT "ODD"
ENDIF

Python 3:

number = int(input("Enter an integer: "))

if number % 2 == 0:
    print("EVEN")
else:
    print("ODD")

MOD in Cambridge-style pseudocode and % in Python both give the remainder in this example. If the remainder after division by 2 is zero, the number is even.

Remember these key points

An algorithm is a finite sequence of clear steps for solving a problem.

Analysis identifies the problem and its requirements.

Design plans the solution.

Coding writes the program.

Testing checks that the program works correctly.

Abstraction removes irrelevant detail.

Decomposition breaks a complex problem into smaller parts.

Input is the data supplied; process is the work done; output is the result.
