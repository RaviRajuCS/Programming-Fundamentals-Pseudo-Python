1. What is selection?

Selection is a programming control structure. It allows a program to make a decision and choose which instruction or group of instructions to execute. The decision is based on a condition or the value of a variable.

A condition is an expression that evaluates to TRUE or FALSE. Relational operators such as =, <, >, <= and >= are commonly used in conditions. Logical operators such as AND, OR and NOT can combine conditions.

2. IF statement – one-way selection

An IF statement without ELSE executes its instructions only when the condition is TRUE. If the condition is FALSE, the program skips those instructions.

Cambridge pseudocode

IF <condition>
THEN
  <statements>
ENDIF

Worked example: Display a message if a student’s score is at least 50.

IF Score >= 50
THEN
  OUTPUT "Pass"
ENDIF

If Score is 62, the condition is TRUE and “Pass” is displayed. If Score is 42, the condition is FALSE and no message is displayed.

3. IF–ELSE statement – two-way selection

An IF–ELSE statement provides two possible paths. The THEN instructions execute when the condition is TRUE. The ELSE instructions execute when it is FALSE. Exactly one path is selected.

Cambridge pseudocode

IF <condition>
THEN
  <statements>
ELSE
  <statements>
ENDIF

Worked example: Decide whether a student has passed.

IF Score >= 50
THEN
  OUTPUT "Pass"
ELSE
  OUTPUT "Not yet passed"
ENDIF

For Score = 38, the condition is FALSE, so the ELSE branch displays “Not yet passed”.

4. Nested IF statements

A nested IF is an IF statement placed inside another IF statement. It is useful when a second decision is needed after the first decision has been made. Indentation helps show which IF each ELSE belongs to.
IF Score >= 50
THEN
  IF Score >= 80
  THEN
    OUTPUT "Excellent"
  ELSE
    OUTPUT "Pass"
  ENDIF
ELSE
  OUTPUT "Not yet passed"
ENDIF

First, the program checks whether Score is at least 50. Only if that is TRUE does it check whether Score is at least 80.

5. CASE statement – multiple-way selection

A CASE statement selects one branch according to the value of a single identifier. It is useful when a variable can have several specific values. Each case is checked in sequence. When a matching value is found, its statement is executed and the CASE statement ends.

Cambridge pseudocode

CASE OF <identifier>
  <value 1> : <statement>
  <value 2> : <statement>
  ...
  OTHERWISE <statement>
ENDCASE
The OTHERWISE clause is optional and, if used, must be the final case. It runs when none of the listed values matches. Cambridge recommends using single values and keeping each branch to a single statement. For more complex conditions, use IF instead.

Worked example: Display the name of a selected day.

CASE OF DayNumber
  1 : OUTPUT "Sunday"
  2 : OUTPUT "Monday"
  3 : OUTPUT "Tuesday"
  OTHERWISE OUTPUT "Invalid day number"
ENDCASE

If DayNumber is 2, “Monday” is displayed. If DayNumber is 7, the OTHERWISE branch is executed.

6. Python 3 comparison

Python uses indentation to define the instructions inside each branch. It uses if, elif and else in lowercase. Python does not use the Cambridge pseudocode keywords THEN, ENDIF or ENDCASE.
if score >= 50:
    print("Pass")
else:
    print("Not yet passed")

For a choice among several values, Python commonly uses if / elif / else:

if day_number == 1:
    print("Sunday")
elif day_number == 2:
    print("Monday")
elif day_number == 3:
    print("Tuesday")
else:
    print("Invalid day number")

Remember: use == to compare values in Python. A single = assigns a value.

8. Cambridge-style exam practice

A school stores a learner’s test mark in the variable Mark. A mark of 50 or above is a pass. A mark of 80 or above earns a distinction.

(a) Write a condition that is TRUE when Mark is at least 50. [1]

(b) Write a nested IF statement that outputs “Distinction” for a mark of 80 or more, “Pass” for a mark from 50 to 79, and “Fail” for a mark below 50. [4]

(c) A variable Option stores a menu selection: 1, 2 or 3. State why a CASE statement may be suitable for processing Option. [2]

Key points to remember

Selection changes the path a program follows, depending on a condition or value.

IF without ELSE has one conditional branch; IF–ELSE has two alternative branches.
Nested IF statements place one decision inside another.

CASE selects a branch based on one identifier’s value. OTHERWISE, when used, comes last.

Follow Cambridge pseudocode layout and indentation in examination answers.

Python uses if / elif / else with colons and indentation; its comparison operator is ==.
