1. What is an array?

An array is a fixed-length data structure that stores a number of elements of the same data type. Each element can be accessed using its index (position) in the array.

For example, an array can store the test marks of 5 students. Instead of declaring five separate variables, one array can hold all five marks.

Important features:

All elements in one array have the same data type.

The number of elements is fixed when the array is declared.

Each element has an index.

An index identifies the position of an element.

2. Declaring a one-dimensional array

Cambridge pseudocode uses DECLARE to create an array. State the lower and upper index bounds and the data type.
DECLARE <identifier> : ARRAY[<lower bound>:<upper bound>] OF <data type>

Example: an array to store 5 integer marks, using indexes 1 to 5.

DECLARE Marks : ARRAY[1:5] OF INTEGER

The array contains five elements: Marks[1], Marks[2], Marks[3], Marks[4] and Marks[5]. Cambridge recommends stating the lower bound explicitly. A lower bound of 1 is commonly used in examples, although the first index can be 0 or 1.

3. Understanding indexes

The index is written inside square brackets after the array name. It identifies one element, not the number of elements.

In this illustration, Marks[3] contains 81. The index 3 means the third position; it does not mean that the array contains only three elements.

4. Writing values into an array

Use the assignment operator ← to store a value in an individual element.
Marks[1] ← 72\nMarks[2] ← 65\nMarks[3] ← 81

The value on the right is stored in the array element named on the left. The assigned value must be compatible with the array data type.

5. Reading and outputting array values

An individual element can be used in INPUT and OUTPUT statements.
INPUT Marks[1]\nOUTPUT Marks[1]

The first statement reads a value into the first element. The second displays the value stored in that element.

6. Traversing an array using iteration

Traversing means visiting the array elements one by one. A FOR loop is commonly used when the index range is known.

Worked example: input five marks and then display them.

DECLARE Marks : ARRAY[1:5] OF INTEGER\n\nFOR Index ← 1 TO 5\n  INPUT Marks[Index]\nNEXT Index\n\nFOR Index ← 1 TO 5\n  OUTPUT Marks[Index]\nNEXT Index

The first loop stores a value in each element. The second loop visits each element and outputs its value. The expression Marks[Index] uses the current value of Index to select the element.

7. Processing array values

An array can be processed while it is traversed. For example, a running total can be calculated by adding each element to Total.

Total ← 0\nFOR Index ← 1 TO 5\n  Total ← Total + Marks[Index]\nNEXT Index\nOUTPUT Total

The variable Total is initialised to zero before the loop. Each array value is then added once.

8. Python 3 comparison

Python lists are commonly used for collections of values. A Python list can grow or shrink, so it is not exactly the same as a fixed-length Cambridge pseudocode array.

marks = [72, 65, 81, 90, 76]

Python list indexes start at 0. Therefore, the first value is marks[0], the second is marks[1], and so on.

print(marks[0]) # displays 72\nmarks[2] = 84 # updates the third value

A loop can visit every value:

for index in range(len(marks)):\n print(marks[index])

Notice the indexing difference: the Cambridge example uses indexes 1 to 5, while this Python list uses indexes 0 to 4.

9. Common mistakes

Using an index outside the declared lower and upper bounds.

Confusing an index with the number of elements in the array.

Trying to store a value of the wrong data type.

Forgetting to initialise a total before adding array elements.

Using the wrong loop bounds and missing the first or last element.

Assuming Python list indexes start at 1; they start at 0.

Key points to remember

An array stores a fixed number of elements of the same data type.

Each element is accessed using the array name and an index in square brackets.

Declare an array by specifying its lower bound, upper bound and data type.

Use iteration to read, write and process all elements efficiently.

Cambridge pseudocode arrays can use a lower index of 0 or 1; state the bounds clearly.

Python lists use zero-based indexing and are not fixed-length arrays.
